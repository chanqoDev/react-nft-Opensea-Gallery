# React NFT Gallery (OpenSea Integration)

---

## Overview
A Web3 application that displays NFTs by integrating with the OpenSea API. Built with React, this project demonstrates fetching and rendering blockchain-based assets in a dynamic frontend interface.

---

## Features
- Fetches NFT data from OpenSea testnet API  
- Displays NFT collections in a responsive gallery UI  
- MetaMask integration for wallet connectivity  
- NFT minting workflow using Thirdweb  
- Deployed and tested on Ethereum (Rinkeby)  

---

## Tech Stack
- React  
- JavaScript (ES6+)  
- Thirdweb  
- OpenSea API  
- MetaMask  
- Ethereum (Rinkeby Testnet)  

---

## How It Works
- NFTs are minted via Thirdweb and deployed to the Rinkeby network  
- Contract data is indexed and accessed through OpenSea testnet API  
- Frontend fetches and renders NFT metadata dynamically  

---

## Getting Started

Install dependencies:
```bash
npm install
npm start
```
